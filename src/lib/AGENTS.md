# src/lib — app infrastructure

No UI, hooks-with-UI, screen or module imports here (lint enforces the layer). Each concern has exactly one home:

- **`db/`** — the local database ([07 §8](../../docs/agent-rules/07-data-state.md)). `client.ts` exports `getDb()`, the only way to open `hive.db` — lazily, never at import time. `schema.ts` holds core (shell) tables such as `home_modules`; module tables live in `src/modules/<id>/data/schema.ts`. `migrations/` is generated by `pnpm db:generate` (drizzle-kit, via `drizzle.config.ts`): committed, lint/prettier-ignored, never hand-edited.

- **`api.ts`** — the only `fetch` in client code (remote integrations; no feature uses it for core data). Typed `api<T>()`, `ApiError(status, message)`, default timeout, `AbortSignal` passthrough. Cross-cutting concerns (auth header, tracing) go here, not at call sites.
- **`env.ts`** — the only `process.env` read in client code (`process.env.EXPO_OS` excepted). Every value is optional (`optional()`), never `required()`: EAS Update bundles are built without `.env`/`eas.json` env, so a throw here crashes every OTA update (#18; regression test `env.test.ts`). A new variable means: add it to `env`, to `.env.example`, and handle it being unset where it is used. Only `EXPO_PUBLIC_*` reach the bundle, and they are public ([01 §5](../../docs/agent-rules/01-architecture.md), [13 §1](../../docs/agent-rules/13-security.md)).
- **`query-client.ts`** — global query defaults (`networkMode: 'always'`: local-first) and the only place for cross-cutting error side effects (`QueryCache`/`MutationCache` `onError`). Don't change global defaults for one screen; override in that query's `queryOptions` ([14 §2](../../docs/agent-rules/14-errors-resilience.md)).
- **`app-info.ts`** — build/update metadata for bug reports.

Module-level code here runs at import time and `_layout.tsx` reaches all of it — a throw at import (for example a missing env var) breaks every bundle, including the CI Android export — and opening the database at import breaks Jest ([review-lessons L-001](../../docs/agent-rules/review-lessons.md)).
