# src/screens — shell screens

Only the shell's own screens live here: Home (the module launcher) and Settings. Module screens live in `src/modules/<id>/screens/` ([src/modules/AGENTS.md](../modules/AGENTS.md)). One folder per screen: `<name>/index.tsx` exports the screen (named export), private pieces in `<name>/components/`. New shell screen: `pnpm new:screen <name>` (screen + test + route), then link to it.

- **Never import another screen or a module's internals.** Shell screens may import `@/modules/registry`. When a second screen needs a component, promote it to `src/components/`. Lint blocks upward imports (screens → app); screen-to-screen imports are caught in review.
- **Data.** Screen-local TanStack Query hooks live next to the screen as `use-<thing>.ts`, with a key factory and a shared `queryOptions`: local SQLite via `getDb()` — copy `home/use-home-layout.ts` (incl. the optimistic mutation); remote via `api<T>()` — copy `settings/use-health.ts`. Pure logic goes in a React-free file with tests (`home/home-layout.ts`). Rules: [07-data-state.md](../../docs/agent-rules/07-data-state.md).
- **Four states, always.** Loading → `LoadingState`, error → `ErrorState` wired to `refetch`, no data → `EmptyState`, then success. If cached data exists, keep showing it when a background refetch fails ([07 §1](../../docs/agent-rules/07-data-state.md), [14 §3](../../docs/agent-rules/14-errors-resilience.md)).
- **Layout.** `ThemedView`/`ThemedText` + tokens, safe-area insets (Home has no header, so it uses `SafeAreaView`), content capped at `MaxContentWidth`, works in light and dark mode ([03](../../docs/agent-rules/03-ui-design-system.md), [04](../../docs/agent-rules/04-responsive-adaptive.md)).
- **Tests** are colocated (`index.test.tsx`), `await render(...)`, `userEvent` for interaction. SQLite-backed hooks are mocked (`jest.mock('./use-home-layout')` — copy `home/index.test.tsx`); remote screens use a fresh `QueryClient` with `{ retry: false, gcTime: Infinity }` and `@/lib/api` mocked, waiting for the _value_ (`waitFor`) — copy `settings/index.test.tsx` ([09](../../docs/agent-rules/09-testing.md)).
- A new user-visible screen or flow also gets a Maestro flow in `.maestro/`.
