# Security policy

Hive keeps all user data on the device. Please report vulnerabilities privately — do not open a
public issue.

## Reporting

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this
repository. Include the app version and runtime (from the card on the Settings screen), the
platform, and steps to reproduce.

You can expect an acknowledgement within 7 days. Fixes ship as an OTA update when only JavaScript
changes, otherwise with the next store release.

## Supported versions

Only the latest production release receives fixes.
